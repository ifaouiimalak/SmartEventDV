SmartEvent - Version sans React

Technologies utilisees : PHP, MySQL, HTML, CSS, JavaScript natif et AJAX.
Aucun React, JSX, Vite, Node.js, npm ou package frontend n'est utilise.

Fonctionnalites gardees :
- inscription et connexion
- espace client
- espace admin
- creation et gestion des evenements
- reservation et confirmation
- QR code de reservation
- favoris
- recherche AJAX
- slider accueil avec photos
- statistiques dashboard
- prix en dinar tunisien
- interface premium responsive

Installation :
1. Copier le dossier smartevent dans D:/laragon/www
2. Creer la base smartevent dans HeidiSQL
3. Importer schema.sql
4. Verifier config/db.php
5. Ouvrir http://localhost/smartevent
